# Waterbirds (sous-ensemble)

Photos de 8 espèces d'oiseaux d'eau, 130 photos par espèce (images originales,
sans les versions augmentées), un dossier par espèce :
greater flamingo, great white pelican, painted stork, eurasian spoonbill,
Bar-headed Goose, Tufted Duck, Northern Shoveler, Common Pochard.

Fichier : `waterbirds.zip` (onglet Releases).
