# Waterbirds (subset)

Photos of 8 waterbird species, 148 photos per species, one folder per species:
greater flamingo, great white pelican, painted stork, eurasian spoonbill,
Bar-headed Goose, Tufted Duck, Northern Shoveler, Common Pochard.

File: `waterbirds.zip` (Releases tab).

## Source

Subset of the Kaggle dataset "waterbirds" (solomonmelwin2002):
https://www.kaggle.com/datasets/solomonmelwin2002/waterbirds
